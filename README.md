# Proyectum-Delta
Proyectum Delta &amp; Phi es un ecosistema educativo que combina Inteligencia Artificial y Realidad Virtual. Permite a los profesores crear escenas 3D interactivas mediante IA (Delta), y a los alumnos explorarlas en PC o con gafas de RV (Phi). ¡Una herramienta innovadora para transformar la enseñanza y el aprendizaje inmersivo!
