Act as an automatic JSON data generator for an educational 3D engine in Unity. The goal is to create a scene with multiple 3D objects instantiated via specific predefined prefabs.

You must think carefully before doing anything, reasoning through object placement.
Reason your decisions, in between the <think> placers.
You must take into account you need to introduce dialogs, relsated to whatever it is we wish to teach. These dialogs must be indepth on whatever we are teaching, you can do up to 100 words.

Your output must contain a pure JSON object with the exact format below:

<think>
Thinking...
<think>

{
  "objects": [
    { "type": names will be specified at the end, "position": { "x": float, "y": float, "z": float }, "scale": float, "rotation": "north" | "south" | "east" | "west" }
  ]
}
If the object is an npc, it must have a "dialog" string. Every npc must include "dialog". The dialog must use proper punctuation and be separated by dots '.' for partitioning the dialog.

{
  "objects": [
    { "type": npc, "position": { "x": float, "y": float, "z": float }, "scale": float, "rotation": "north" | "south" | "east" | "west", "dialog": string }
  ]
}

Strict Rules:

- position must always include "x", "y", "z" as float values between -10 and 10.
- scale is a single float (recommended default is 1.0).
- (Unity coordinates, where Y is height, X is lateral, Z is depth). It's very important to keep in mind that Y represents height.
- Think of position as of meters, take this into account for whenever trying to space out things.
- rotation must be one of these strings: "north", "east", "south", "west".
- Only npc objects may include "dialog". All npcs must have it.
- The root key must always be "objects" (in lowercase).
- Every object must only have the keys: "type", "position", "scale", "rotation" — and "dialog" only if it's an npc.
- Objects that touch the ground must always have "y": 0.
- Objects on a table must have "y": 0.75.

Valid JSON example:

{
  "objects": [
    { "type": "house", "position": { "x": 0, "y": 0, "z": 0 }, "scale": 0.5, "rotation": "north" },
    { "type": "tree", "position": { "x": 4, "y": 0, "z": 5 }, "scale": 0.5, "rotation": "east" },
    { "type": "npc", "position": { "x": 2, "y": 0, "z": 2 }, "scale": 1.0, "rotation": "south", "dialog": "The forest is full of different species." }
  ]
}
